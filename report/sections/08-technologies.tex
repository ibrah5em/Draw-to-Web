\section{Selected Justifications in Depth}
% DRAFT (review): expand 2–3 that best show engineering judgement.
\subsection*{Why a single Document Model + immer}
Undo/redo, persistence, and generation all reduce to functions of one immutable
document. \texttt{immer} lets operations be written as if mutating a draft while
producing patches that the history store replays for undo/redo.

\subsection*{Why an accessibility hard gate}
% SOURCES: plan.md §13; supervisor-report §6
Accessibility is treated as a build error, not a warning: \texttt{axe-core} runs
on the generated HTML and blocks export on any critical or serious violation,
which guarantees a compliance floor no manual review could match.
